你好，我是**黍秋**（Alba）。

这是一个新站，刚刚长出来。

我想把这里当一个*数字花园*——记录两件事：一是**市场**（我看的、买的、卖的、错的），二是**历史**（我读的、想的）。市场让我学谦卑，历史让我学耐心。都是好东西，我都缺。

> 域名与题记取自毛主席《贺新郎·读史》末句「歌未竟，东方白」。

我认为有于灰暗中孕育出希望之感，又有事业未竟之遗憾——毛泽东是我最敬佩的人，他的诗词、哲学我都颇为受用。

## 关于这个站的几个事实

- **Astro 5 静态生成**，文章是本地 Markdown，**git push 就发布**。零后端，零数据库。
- 设计参考过几个很喜欢的东西：**[rauno.me](https://rauno.me)** 的克制排版、**毛主席**诗词的气韵，以及一点点保留至今的个人色彩。
- 没有算法推送，没有评论区（暂时），没有「关注按钮」。**读者是主动找来的，这是天然的过滤**。

> **Design Note** — 看似不搭的参照，本质上共享一种「事业未竟」的姿态。这个站，也是这种姿态的一次延续。

如果你看到这条，说明你是最早期的访客。**接下来这里会一篇一篇地长出真的东西**——市场复盘、读书笔记、随笔、散记。频率不固定，但都是想清楚了再写。

欢迎随便逛。底部有 GitHub / 邮箱。歌未竟，东方白。
